# Health Assistant

This is a full-stack web application that provides a health assistant dashboard.

## Project Structure

- `frontend/`: Contains the frontend code (HTML, CSS, JavaScript).
- `backend/`: Contains the backend code (Node.js, Express).

## How to Run in VS Code

1.  **Open the project in VS Code.**
2.  **Open a new terminal.**
3.  **Install backend dependencies:**
    ```bash
    cd health-assistant/backend
    npm install
    ```
4.  **Start the server:**
    ```bash
    node server.js
    ```
5.  **Open your browser and navigate to `http://localhost:3000`** to see the application running.
